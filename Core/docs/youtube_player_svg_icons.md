## 💡 Cómo integrarlos en Flutter (AurisTV)

Puedes usarlos directamente creando un widget wrapper o con `flutter_svg` con `SvgPicture.string()`:

```dart
import 'package:flutter_svg/flutter_svg.dart';

Widget buildYouTubePlayIcon({double size = 28, Color color = Colors.white}) {
  return SvgPicture.string(
    '''<svg viewBox="0 0 36 36"><path fill="${color.toHexString()}" d="M 17 8.6 L 10.89 4.99 C 9.39 4.11 7.5 5.19 7.5 6.93 L 7.5 29.06 C 7.5 30.8 9.39 31.88 10.89 31 L 17 27.4 L 17 8.6 Z M 17 8.6 V 27.4 L 33 18 L 17 8.6 Z"/></svg>''',
    width: size,
    height: size,
  );
}
```
